# Playback V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace segment-first playback navigation with a Protect-inspired continuous timeline that seeks by wall-clock time while reusing all existing playback sources and compatibility behavior.

**Architecture:** Keep recording storage and playback APIs unchanged. Add pure timeline math utilities and a focused `PlaybackTimelineV3.vue`; move exact seek ownership into `RecordingManagementView.vue` using a real video ref and pending seek state, then retire the Motion Teleport/MutationObserver layer.

**Tech Stack:** Vue 3, TypeScript, Vitest, Element Plus, existing FastAPI recording and motion APIs.

**Spec:** `docs/superpowers/specs/2026-09-13-playback-v3-design.md`

## Global Constraints

- Preserve direct original playback, H.264 compatibility proxy/live proxy, and OpenList cloud playback.
- Do not fake person/vehicle event data.
- Motion events remain real API-backed data.
- Timeline zoom levels are exactly 24h, 6h, 1h, and 15m for V3.
- A timeline seek into a recording gap must not change playback.
- Wall-clock calculations must remain independent of the browser's local timezone.
